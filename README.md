# Agent skills

My personal agent skills.

## parse-pdf

Parses a PDF with [markitdown](https://github.com/microsoft/markitdown). Assumes it is available on your `PATH` (I use [this](https://github.com/andrewrjones/bin/blob/master/markitdown)).

## proof-read-blog

Proof read a draft blog post.

Note: I never use AI to write my posts, only to review.
